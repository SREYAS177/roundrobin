# SDG Round Robin Scheduling Simulator

An interactive CPU scheduling simulator developed for an Operating Systems assignment using Python and Google Colab.

## Activities

- **Activity 1:** Municipal Sustainability Services — SDGs 6, 11 and 12.
- **Activity 2:** Emergency and Environmental Monitoring.

## Features

- Round Robin CPU scheduling
- Adjustable time quantum
- Configurable context-switch cost
- Animated Gantt chart
- Step-by-step simulation controls
- Waiting time, turnaround time and response time
- CPU efficiency and context-switch analysis

## Technologies Used

- Python
- Google Colab
- Matplotlib
- IPython Widgets

## How to Run

1. Open the notebook in Google Colab.
2. Run the code cell.
3. Select Activity 1 or Activity 2.
4. Set the time quantum and context-switch cost.
5. Click **Run Simulation** to view the results.
